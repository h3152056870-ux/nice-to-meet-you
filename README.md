# 100年润发 · NICE TO MEET YOU
## 3D 品牌数字快闪店 / A DIGITAL FLAGSHIP EXPERIENCE

一栋位于晴朗城市街道中的二层 100年润发品牌快闪店。建筑以奶油白、香槟金与品牌绿构成，大面积透明玻璃后陈列产品、茶饮联名、Keep 运动企划与东方美学展陈；门前是巨型「控油小茶瓶」户外雕塑。

空间索引分为 **外观 / 一楼 / 二楼** 三种观看方式：外观是实时 3D 街景，一楼与二楼则进入单独制作的鸟瞰剖面广角场景。点击空间节点后，内容页以磨砂玻璃的形态浮在空间背景之上。

### 打开方式

- **本机预览**：<http://127.0.0.1:5193/>
- **离线单文件**：双击 `NICE-TO-MEET-YOU.html`。所有 JS、CSS、3D 贴图、产品图、品牌 LOGO、活动图片与楼层鸟瞰图均已内联，无需联网。
- **正式构建**：`npm run build`
- **重新打包单文件**：`npm run build:single`

### 空间与交互

| 操作 | 效果 |
| --- | --- |
| 右侧「外观 / 一楼 / 二楼」 | 在实时 3D 街景与两层鸟瞰剖面广角场景之间切换 |
| 外观模式 | 实时 3D 建筑：树木随风轻摆、行人走动、有人进入/离开快闪店 |
| 一楼 / 二楼模式 | 打开对应楼层的鸟瞰剖面大图作为背景，并显示该层 6 个空间节点 |
| 悬停空间节点 | 显示节点名称；外观模式下同步点亮 3D 场景中的对应区域 |
| 点击空间节点 | 打开磨砂玻璃质感的 2D 品牌专题页 |
| 点击一楼巨型小茶瓶 | 进入一楼，并直接打开「01 产品初见」 |
| 关闭 / Esc / 点击遮罩 | 返回当前楼层的鸟瞰空间 |
| ← → / 底部翻页 | 在同层 6 个节点间切换 |
| 拖动画面 | 外观模式下受限微调视角，不会穿墙或进入建筑 |
| RESET VIEW | 回到预设建筑视角 |

6. 内容延展：三部微短剧、双平台直播与整合传播闭环

### 技术与实现

- Three.js r170 + Vite 6
- 程序化 3D 建筑、街道、屋顶花园、树木、家具、邻居小店、花房、公交站、自行车与行人
- 二楼增加中央社交长桌、NICE 地毯、后场会客区、茶饮吧台与东方美学展示
- 一楼/二楼鸟瞰图为单独搭建的剖面场景渲染，并作为楼层背景接入
- 12 个独立 2D 专题页由 `src/content/data.js` 数据驱动
- 玻璃质感内容页：半透明奶油底色 + 背景模糊 + 高光描边
- 实时风动树冠、行走动画、进店/离店淡出、跟随式接触阴影
- 静态几何合批与静态阴影缓存，保留动态人物和树冠
- 移动端下调整为底部三层索引、楼层背景与大图内容页
